
# api-platform-get-apis-lambda

Lambda function to get a list of APIs in AWS API Gateway and return the list as JSON.

## Build docker container locally
To build this locally run:

`make build TAG="test"`

## Run tests locally
To run the tests locally:

`make test-locally`
